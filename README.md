# Fridge-to-Recipe-Suggester

A hackathon project that suggests recipes based on the ingredients available in a user's fridge.

## Team Project

This project was developed collaboratively as a team.

## My Contribution

I worked on the **frontend development using HTML**, including creating and structuring the web pages and user interface.

## Technologies Used

- HTML
- Python

## Project Description

The Fridge-to-Recipe-Suggester helps users find recipe suggestions based on the ingredients they have available.
